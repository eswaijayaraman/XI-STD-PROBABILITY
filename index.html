Learning Tip for Slow Learners

Probability is simply: (Favorable Outcomes) ÷ (Total Possible Outcomes). Keep track of sample space S first before solving any probability question!

Foundation

Sample Space (S)

The set of all possible outcomes of a random experiment.

Coin Toss: S = {H, T} &implies; n(S) = 2
Two Coins: S = {HH, HT, TH, TT} &implies; n(S) = 4
Single Die: S = {1, 2, 3, 4, 5, 6} &implies; n(S) = 6
Core Rule

Addition Theorem

Probability of event A OR event B occurring.

General Rule:
P(A ∪ B) = P(A) + P(B) - P(A ∩ B)
• A ∪ B means "A or B"
• A ∩ B means "A and B"
Key Concept

Mutually Exclusive Events

Events that CANNOT happen at the same time.

Condition: A ∩ B = ∅ (Empty Set)
P(A ∩ B) = 0
Simplified Sum: P(A ∪ B) = P(A) + P(B)
Shortcut

Complementary Event (Not A)

The event that A does NOT happen, written as A' or Not A.

P(Not A) = 1 - P(A)
Total Probability: P(A) + P(Not A) = 1
Tip: "At least 1" = 1 - P(None)
Definition

Exhaustive Events

Events whose union covers the entire sample space S.

Condition: E1 ∪ E2 ∪ ... ∪ En = S
P(E1) + P(E2) + ... + P(En) = 1

Quick Probability Cheat Sheet

Basic Definition
Probability of Event E: P(E) = n(E) / n(S)
Range of Probability: 0 ≤ P(E) ≤ 1
Impossible Event: P(∅) = 0 | Sure Event: P(S) = 1
Addition Theorem & Set Formulas
General Union: P(A ∪ B) = P(A) + P(B) - P(A ∩ B)
Mutually Exclusive: P(A ∩ B) = 0 &implies; P(A ∪ B) = P(A) + P(B)
Complement: P(A') = 1 - P(A)
Quick Set Equivalences
• P(A but not B) = P(A - B) = P(A) - P(A ∩ B)
• P(Neither A nor B) = P(A' ∩ B') = 1 - P(A ∪ B)
